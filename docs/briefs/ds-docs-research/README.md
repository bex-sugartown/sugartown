# Design system docs research

Research and artifacts for the design-system docs PRD. Tracked by [#148](https://github.com/bex-sugartown/sugartown/issues/148); epic doc `docs/backlog/ST-148-design-system-docs-research-prep-for-cloud-prd-session.md`.

## For a cloud session reading this

Everything the session needs must be in this directory or elsewhere in the repo. These are not visible to it:

- `docs/drafts/` (gitignored)
- `SUGARTOWN_DEV/conventions/` and `~/.claude/` (outside the repo)
- iCloud Drive, Apple Notes, and any other local file

The first message of the session carries the key rules from `human-instruction-style.md` and `human-gate-conventions.md`.

## Contents

Research notes go here as markdown, one topic per file. The PRD is drafted here with the `sugartown-prd-writer` skill.
