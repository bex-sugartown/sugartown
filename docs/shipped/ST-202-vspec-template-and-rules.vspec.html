1. What the template is

One copyable file, docs/conventions/vspec-template.html, plus a rules doc, docs/conventions/vspec-rules.md. A session copies the template into docs/drafts/ as ST-{N}-{slug}.vspec.html and fills the ten sections below. It links tokens.css and theme.pink-moon.css by relative path (same depth in both folders). It defines no colour, font or spacing of its own. A sticky toggle sets data-theme on the root element between light-pink-moon and dark-pink-moon. Light is the default.

2. The ten fixed sections, in order

Each section keeps its number and title in every vspec. An unused section stays and says "Not applicable" with the reason, so a reviewer can tell skipped from forgotten.

Text pairs this page uses, each measured in both views on 2026-11-07. Text needs 4.5:1. The pass and fail borders are non-text and need 3:1.

What the measurement caught: the first draft coloured the pass and fail words with the signal tokens. Light measured 3.54:1 and 3.20:1, which fails text contrast, so the words now use the default text colour and the signal colour moved to a border. Dark was already above 4.5:1.

Command: a browser script, saved at /private/tmp/claude-502/-Users-beckyalice-SUGARTOWN-DEV-sugartown/ff046e07-1d8e-4ddc-9b6e-5d980b56fe8a/scratchpad/measure-vspec-contrast.js, run in the page opened over a local server. It switches data-theme, reads each element's computed colour, composites every ancestor background over white (needed because the dark surface is a translucent white wash), and applies the WCAG relative-luminance formula. pnpm validate:contrast was also run: every derived colour pair meets AA, with 25 allowlisted. It checks token pairs, not this page's composited pairs, so it does not replace the script. Phase 2 commits the script into the rules doc so a later session does not depend on a scratch file.

8. Component choice audit

No site component is used or changed. The template is a static HTML file under docs/conventions/. The toggle is a plain button with template-only styles because the DS Button is a React component and the template has no build step. No new DS primitive.
