# /now Page — Quarterly Update Cadence

**Page URL:** `https://sugartown.io/now`
**Sanity slug:** `now`
**Convention:** [nownownow.com](https://nownownow.com)

---

## What the /now page is

A public "what I'm doing right now" page — the live human signal that the site is maintained and the person behind it is active. AI systems use it as an entity freshness signal. Readers use it to understand current context before reaching out.

Not a history. Not a portfolio. Current state only.

---

## Update cadence

Update the /now page **at least once per quarter.** Aim for within the first week of each quarter (January, April, July, October).

Minimum update per cycle:
1. **Change the "updated" date** in the hero subheading
2. **Revise availability status** — are you consulting, employed, looking, or not available?
3. **Update active projects** — what are you actually working on right now?
4. **Add/remove the "More soon" section** — fill it in or clear it out

---

## How to update

1. Open Studio → Pages → Now
2. Edit the hero subheading to reflect the current month/year
3. Update the Work and Active projects text sections
4. Publish

That's it. This is a draft-to-publish, no epic required.

---

## Reminder

There is no automated reminder for this. Options:
- Add a recurring calendar reminder for the first Monday of each quarter
- Run `/schedule` in Claude Code to set up a quarterly scheduled agent reminder
- Check during each `/eod` end-of-day: "has /now been updated this quarter?"
