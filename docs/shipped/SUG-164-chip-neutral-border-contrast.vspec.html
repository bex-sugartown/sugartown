5. Surfaces this reaches

  • Chip neutral chassis and .ruleDot (Chip.module.css), so every tag and status chip.
  • Card .statusBadge and .folioStatus (Card.module.css).
  • Rubric chip via --st-chip-rubric-border.
  • Knowledge-graph article and case chips via --st-kg-chip-*-border.
  • Not reached: tinted opt-in chips, status dots, border-wrap, table cell borders, dividers.

6. Annotations

What you will notice: chip outlines become visibly firmer, close to a mid-grey rule instead of a pale hairline. Text, fill and size do not move. The pink stays the only hot colour.
Interaction states: hover and active states already override the border in Chip.module.css and keep winning, because the neutral rule is wrapped in :where(). No change to them.
Navigation surface: not applicable. This is not a nav, sidebar or tab bar.
Prototype triggers: none fire (no scroll-spy, filtering, expand, tab, sticky, drag or persisted state), so this spec carries no script.

7. Sign-off

Approve this spec, or name what to change: a lighter light value (a lower contrast would drop under 3:1 against the canvas, so the floor is about #8c8c8f at 3.00:1), a different dark value, or a different approach.
