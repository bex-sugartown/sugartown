2 · Behaviour

EventWhat happens
First visit, no stored choiceBar shows after the app mounts. Focus is not moved. Page gets bottom padding equal to the bar's measured height. No animation.
AcceptStore st-consent = {"analytics":"granted","v":1}. Send gtag('consent','update',{analytics_storage:'granted'}) and inject gtag.js (basic mode: not loaded before this). Bar hides, padding removed.
RejectStore {"analytics":"denied","v":1}. Bar hides. If GA had been granted earlier: send consent update denied and delete the _ga and _ga_* cookies on the domain.
Return visitStored choice read before first paint in index.html. granted loads GA at once; denied or none loads nothing. Bar shows only when nothing is stored, or v is older than the current version.
Footer "Cookie settings"Reopens the bar with the meta line showing the current choice. Focus moves to the first button.
After a choiceFocus returns to "Cookie settings" if the bar was opened from there; otherwise to <main>.
Escape keyDoes nothing. There is no close (×) button: leaving it open is allowed, dismissing without a choice is not.
Keyboard orderBar renders after the footer in the DOM, so it is reached after page content. It never traps focus.
LocalhostBar shows (so it can be tested). GA stays suppressed exactly as today.
Prerendered pagesBar appears once the SPA bundle mounts. GA loading on these pages is #128, which reuses this consent check.

3 · Layout contract

  • .fixedBar: fixed to the viewport bottom, full width, z-index: 150 (Header 100, Drawer 199/200, Lightbox 1000). Side and bottom inset --st-page-gutter.
  • .fixedBarInner: max-width: var(--st-width-site) (1200px), centred, --st-shadow-elevation-float.
  • Bar surface is the existing Callout banner: --st-card-label-bg fill, 2px pink top rule, 1px --st-color-rule-accent sides, radius 0.
  • Wide: label · text · buttons in one row. When the text would drop under about 32 characters wide, the buttons wrap under it (flex-wrap, no breakpoint). At 640px and below: label, then text, then the two buttons in two equal columns.
  • Both buttons are DS Button variant="secondary" size="sm": identical, so neither choice is nudged.
  • Dark mode: token inheritance only. No component-level dark rules.
