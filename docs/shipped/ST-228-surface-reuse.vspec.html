9. Decisions answered

  1. Toggle chips: answered 2026-11-15, as drawn: swap both to DS Chip and take Chip's look (normal-case 12px, ink when active). Alternative: keep today's uppercase pink look as one shared class, no DS swap.
  2. Web Select: answered 2026-11-15, as drawn: delete it (nothing renders it). Alternative: keep it and match Input's surface.
  3. Trust stat grid: answered 2026-11-15, as drawn: keep .tileGrid (Grid's 200px minimum clips the fourth tile). Alternative: Grid at 2 columns everywhere, which turns today's desktop row of 4 into 2 by 2.
  4. Version badge home: answered 2026-11-15, as drawn: new web VersionBadge component. Alternative: a tinted-fill option on DS Chip.
  5. StatCard vs Tile, web Callout: drawn: StatCard/Tile to a separate issue; web Callout deleted as dead. (2026-11-15, decided by the epic's "decide at Phase 0" scope line.)
  6. Form error: drawn: no shared component; one caller once the dead copy is deleted. (2026-11-15)
